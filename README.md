# Задачник — To-Do List, три варианта дизайна

Простой список задач прямо в браузере: **добавить, отметить выполненной, удалить, автосохранение** после перезагрузки страницы.

Задача одна, дизайн — три варианта в одном репозитории. Логика (JS) во всех полностью одинаковая, различается только оформление.

## Открыть рабочий сайт

Страничка выбора: **https://zolotarevmikhail.github.io/todo-app/**

- [Вариант 1 — Спокойный светлый](https://zolotarevmikhail.github.io/todo-app/variant-1.html) — off-white, один зелёный акцент, стиль Todoist
- [Вариант 2 — Технологичный](https://zolotarevmikhail.github.io/todo-app/variant-2.html) — белый фон, градиентные пятна, стеклянная карточка, стиль Framer
- [Вариант 3 — Тёмный лендинг](https://zolotarevmikhail.github.io/todo-app/variant-3.html) — тёмный hero, окно-мокап приложения, стиль Linear

## Что внутри

- один `index.html`-файл на вариант — HTML + CSS + JS вместе, **без внешних библиотек и CDN**;
- данные живут в `localStorage` браузера — задачи не пропадают после перезагрузки и ничего не отправляется в интернет;
- фильтры «Все / Активные / Выполненные», счётчик и полоса прогресса, «Очистить выполненные»;
- защита от битых данных: повреждённый `localStorage` не ломает страницу — список восстанавливается сам;
- адаптив от 400px, клавиатура работает: отметка задачи Enter/пробелом, добавление Enter.

## Состав репозитория

```
index.html      ← страничка-выбор варианта
variant-1.html  ← вариант 1 («Спокойный светлый»)
variant-2.html  ← вариант 2 («Технологичный»)
variant-3.html  ← вариант 3 («Тёмный лендинг»)
README.md
```

## Как запустить локально

Открыть любой `variant-N.html` двойным кликом — работает сразу, сервер не нужен.

## Как работают данные

Задачи хранятся в `localStorage` браузера под ключами `todo-variant1-v1` / `todo-variant2-v1` / `todo-variant3-v1` — у каждого варианта свой список, они не мешают друг другу. Данные чисто локальные: очистка хранилища или другой браузер = пустой список.
